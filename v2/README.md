# 养鹅计划 V2：手机优先只读原型

这是可以点击体验的四页软件原型，用于审核界面和操作流程。**全部账户、金额、数量、参考价格及报告都是固定虚构样例，不是实时行情或投资建议。** 页面刷新不会更新数据，也不会生成买卖信号。

本目录独立运行，不读取 V1.1 的 SQLite 数据库、持仓文件、Bark 配置或 Draft PR #3 的数据；不改动原有 Windows 14:50 定时任务和模拟通知。没有云端部署、券商接口、真实数据导入或自动下单。

## 先在电脑打开

推荐在 Windows 中双击本目录的 **`启动预览.cmd`**。

下载后先解压到独立的新目录，无需覆盖、更新或移动现有 V1.1 安装。普通浏览器需要支持现代 JavaScript 与原生 dialog（建议使用仍受支持的 Safari、Edge 或 Chrome）。

1. 使用电脑已有的 Python 3.12 或更新版本启动预览，不运行 `pip`，不自动安装或升级软件。
2. 浏览器会打开 `http://127.0.0.1:8765/`；此模式只允许本机访问。
3. 保留预览窗口即可继续使用。关闭窗口或按 `Ctrl+C` 停止，不会留下后台服务或新增计划任务。

若提示找不到 Python，脚本会停止，不会修改原有环境。可由维护者使用已有的 Python 3.12 或更新版本运行 `preview.py`；不要为预览更改 V1.1 已运行的环境。端口被占用时，先关闭旧预览窗口；维护者也可用 `--port` 指定其他端口。

也可尝试直接双击 **`index.html`**，作为不启动服务器的桌面预览。它使用本地脚本和资源，不需要下载依赖，但 `file://` 是否允许加载由浏览器策略决定，也不能注册 Service Worker。本轮 Chromium 管理策略禁止打开本地文件，因此没有完成此方式的浏览器实测；以本地服务器方式为推荐入口。

## 用 iPhone 体验

1. 让 iPhone 和 Windows 电脑连接同一个可信 Wi-Fi。
2. 在电脑双击 **`手机同网预览.cmd`**，保留弹出的窗口。
3. 用 iPhone 的 **Safari** 打开窗口显示的 `http://电脑IPv4:8765/` 地址。手机不要输入 `127.0.0.1`，那会指向手机自己。
4. 结束体验后关闭电脑的预览窗口。

同网模式显式监听电脑的所有网络接口，没有登录验证；它只提供白名单内的公开虚构演示资源，不提供仓库目录、文档、测试、数据库或文件上传。仅在信任的网络中临时使用，勿放入真实账户资料，勿设置路由器公网端口映射。

首次访问可能出现 Windows 防火墙提示。仅在可信的**专用网络**中允许本次 Python 预览访问，不需要关闭防火墙或开放公共网络。宿舍／校园 Wi-Fi 可能启用设备隔离，即使连接同一 Wi-Fi 也无法互访；先核对电脑 IPv4 和网络策略，可在可信家庭网络或个人热点下重试，不需要绕过校园限制。

Safari 中可尝试通过“分享 → 添加到主屏幕”建立入口；选项及表现取决于 iOS 版本。**本轮没有 iPhone 或 Windows 实机验收。** 手机尺寸浏览器截图不等于 iPhone Safari 实测。

## 四页怎样使用

手机底部导航与电脑左侧导航都可以切换页面；点进详情后可用页面返回链接或浏览器返回操作。

| 页面 | 本期可体验内容 | 需要知道的边界 |
| --- | --- | --- |
| 首页 | 已知资产摘要、重点关注、今日市场占位、最新研究记录、数据时间；点击眼睛图标隐藏／显示金额和数量；查看数据状态弹窗 | 资产只合计已知部分，银河现金未知；市场数据尚未接入，未编造涨跌幅 |
| 持仓 | 在全部／华宝／银河间筛选；打开证券详情；展开快照及 T+1 字段说明 | 历史可卖数量不是当前可卖额度；券商成本不是累计收益；未知成本和现金显示“未知” |
| 策略 | 分别查看长期加仓、日内做T的研究依据、数据限制、验证状态及相关报告 | 两套研究独立；均未验证，均显示“无法形成可靠建议”，没有价格、数量或资金操作条件 |
| 报告 | 按全部／长期／做T／数据筛选；进入详情查看依据、风险与失效条件、当时的数据时间和版本 | 全是固定虚构历史记录，没有真实成交或收益评估；刷新不会把历史报告变成当前建议 |

隐藏金额只改变当前页面会话中的显示，刷新后恢复；不会删除样例数据，也不是身份验证或安全保护。账户筛选和报告筛选同样不持久保存。

“月度投资预算”“成交确认”“Bark 提醒”“安全同步”四个预留入口可打开说明弹窗，也可以从右上角设置入口访问。**它们没有输入、保存、发送或真实写入功能。** 不需要填写真实持仓、券商账号、密码或 Bark 密钥。

## 离线和 PWA 的实际范围

项目已提供 manifest、图标和 Service Worker。首次在支持的安全上下文中完整加载并成功安装缓存后，可以离线访问**公开虚构演示**；电脑的 `localhost`／`127.0.0.1` 通常属于可用的安全上下文。

手机通过局域网 IP 的普通 HTTP 地址可以体验网页，但不具备完整离线 PWA 条件，不承诺手机断网可用。可信 HTTPS 后才能进一步验证手机安装和离线行为；本期不部署 HTTPS，也不要求安装证书。

缓存只覆盖白名单内的演示资源，包括 `demo-data.js`；不拦截 API、私有报告、写请求或带查询参数的地址。未来接入真实资料时必须重新审核缓存和身份验证，不能直接把真实持仓替换进这个公开演示缓存。数据约定见 [DATA-CONTRACT.md](DATA-CONTRACT.md)。

## 依赖和维护范围

| 用途 | 要求 |
| --- | --- |
| 页面运行 | 原生 HTML、CSS、JavaScript；零第三方运行依赖，无 CDN、外部字体或外部接口 |
| 本地预览 | Python 3.12 或更新版本，仅标准库；启动脚本不安装软件 |
| JavaScript 单元测试 | Node.js 18 或更新版本，使用内置测试模块；普通用户预览不需要 Node.js |
| 浏览器验证 | Playwright 仅用于开发验证，没有安装到项目运行环境，不属于运行依赖 |

V2 不变更原依赖锁文件。原项目依赖及测试继续使用隔离的虚拟环境，不与本原型混装。具体检查、结果和限制见 [VALIDATION.md](VALIDATION.md)，本文不预设测试通过数量。

新增文件的完整清单见 [FILES.md](FILES.md)。

若暂不继续使用，关闭预览窗口即可；V2 不会改变 V1.1 的任务、数据库或通知。浏览器可能仍保留虚构演示缓存，需要时可在浏览器的网站数据设置中清除本预览地址的数据。后续真实数据、策略、认证、同步及推送应分别验收，本原型不代表这些能力已经上线。
