# 养鹅计划：今晚用 iPhone 查看真实持仓

遇到 98d5425 的“分享启动后自动停止”，请使用最新 PR #5 修正版；见[自动停止修复与最短复验](连接自动停止复验.md)。同一窗口内重试保留所选文件，诊断只需复制固定码，不需要发送原始状态。

这是只读入口：读取你在电脑明确选中的 P1 JSON，不连接券商、不自动交易、不修改原文件。真实数据留在你的 Windows 和获准 iPhone，不上传 GitHub。原 V1.1、Bark 和定时任务不受影响。

## 1. 两端先连接 Tailscale（首次需要你本人操作）

1. Windows 安装[官方 Tailscale](https://tailscale.com/download/windows)，iPhone 在 App Store 安装 Tailscale。已有安装不用重装；电脑要求正式版 1.90.9 或更新。
2. 两端登录**同一个自己的私人账号**。在 iPhone 允许添加 VPN 配置，连接 Tailscale；电脑也保持连接。
3. 在 [Tailscale 后台 DNS](https://login.tailscale.com/admin/dns) 开启 **MagicDNS** 和 **HTTPS Certificates**。不要开启 Funnel。若官方页面要求确认启用 HTTPS，请你本人确认。

不用同一个 Wi-Fi，不用路由器端口映射，不用放行 Python 到公网，不用券商密码或 API 密钥。程序不替你登录，也不改 ACL、防火墙、计划任务或原有分享。

## 2. 下载代码，双击真实入口

1. 下载 [PR #5 分支 ZIP](https://github.com/hengha298-maker/quant-trading/archive/refs/heads/codex/goose-v2-mobile-prototype.zip)，**全部解压到新的独立文件夹**。不要覆盖旧的 V1.1/P1 代码或数据。
2. 打开解压目录的 `v2` 文件夹，双击 **`iPhone真实持仓只读.cmd`**。不要选名字带“虚构测试”的旧入口，也不要双击 HTML。
3. 点击“刷新设备”，在下拉框选自己的在线 iPhone。
4. 点击“1. 选择P1源码”：选择此前已验收的 **PR #3 代码目录或其中的 p1 文件夹**，里面应有 `goose_research`。**这不是 GooseResearchP1 私人数据目录。** 如果旧源码版本不匹配，可另下载 [PR #3 分支 ZIP](https://github.com/hengha298-maker/quant-trading/archive/refs/heads/codex/goose-v2-p1-readonly.zip) 并解压到独立目录，再选其中 `p1`。
5. 点击“2. 选择持仓快照”：选择你要展示的 `GooseResearchP1\snapshots\某个文件.json`。对话框默认定位 `%LOCALAPPDATA%\GooseResearchP1\snapshots`，可以手动换到你实际保存的位置。**不会自动扫描、选择最新文件或根据聊天数字造持仓。**
6. 点击“3. 选择行情”：在**同一个 GooseResearchP1** 的 `market` 文件夹中，按住 Ctrl 选择对应两只证券的行情 JSON；每只证券只选一份明确的日线批次。可以留空，此时显示“尚未提供日线”，不补演示价格。
7. 点击 **“启动分享”**，核对确认框中的 iPhone 名称和 Tailscale IP，确认授权本次设备。等待窗口显示“真实持仓只读分享已启动”。

无需 Git、Node、pip 或重新安装依赖。启动器优先使用此前 K2 Python；找不到时使用现有 Python 3.12 的 `py -3.12`。本版本不自动安装软件。

P1 数据目录必须保留原有 `.local-only` 确认标记，位于本地固定磁盘、非 Git 仓库、非云同步路径。**不需要重导入或改动原数据。** 若路径被拒绝，不要把原文件搬进代码仓库或手工伪造标记；先核对是否选中了此前已成功生成 P1 报告的同一个目录。

## 3. iPhone Safari 打开

1. 电脑点“复制手机地址”，把**不含配对码**的地址发送给自己的 iPhone，用 Safari 打开。
2. 地址形如 `https://电脑名.私网名.ts.net:8443/readonly/`。**只用窗口提供的 HTTPS 地址；不要改成 HTTP、局域网 IP 或公网地址。**
3. 在手机输入电脑窗口的 8 位一次性配对码。配对码 5 分钟有效、最多 5 次失败、用过即失效；会话最长 15 分钟，不自动续期。
4. 首页应标明“真实持仓只读”。持仓页按选定快照显示两个账户的数量、可卖数量和券商成本。行情日期与来源来自所选文件，和持仓快照日期分别展示。

未知现金和成本显示“未知”；真实零仍显示零。可卖数量仅对应该快照，不推算今天可卖量。515450 新浪行情仍只显示原始历史数值及限制，不计算市值、盈亏、费用或交易建议。总资产显示“暂无法完整估值”属于正确结果。

## 4. 撤销、结束与更新数据

- **撤销授权**：关闭本次分享，废除会话和配对码、释放持仓内存。需要重新选择确认设备并启动，才能再次访问。
- **停止分享**：同样关闭本次服务和授权。用完点击它，再关闭窗口；电脑需开机且窗口保持运行才能分享。
- **更新配对码**：保持本次指定设备及数据批次，废除旧会话，生成新的 5 分钟配对码；15 分钟会话到期时也用此按钮。
- 要换持仓或行情，先停止分享，再重新选文件并启动。手机“重新读取当前批次”只重读已发布的内存批次，不重新扫描硬盘或自动更新行情。

网络离线事件、隐藏/离页会清空手机数据；401/403、连接失败或 8 秒请求超时也会清空。电脑撤销/停止后，前台手机会在下次检查清屏（检查间隔 15 秒，慢请求最多再等 8 秒），也可点手机“重新读取当前批次”立即检查。切回前台会重新验会话。没有浏览器持久持仓缓存或离线查看；应用无法撤回你自己拍的截图。

今晚只需实机核对：**选定文件是否正确显示，以及停止分享后手机是否清屏。** 大量错设备、错码、盗 Cookie、非法文件、断线和迟到响应测试由自动化执行，无需你逐项重复虚构演练。

## 常见阻塞：需要你亲自完成的步骤

| 窗口或 Safari 情况 | 处理 |
| --- | --- |
| 找不到 Tailscale / 未连接 | 在官方应用安装、登录并连接两端，再刷新设备。需要安装/VPN权限时由你批准。 |
| 找不到 iPhone | 手机上打开 Tailscale 并连接；确认同一账号。只支持自己的在线 iOS 设备，不支持分享或标签节点。 |
| HTTPS 未启动 | 到后台确认 MagicDNS 和 HTTPS Certificates；完成官方启用确认后重新启动分享。程序不会退回 HTTP。 |
| Safari 证书警告 | 停止访问，检查地址、两端系统时间、Tailscale登录及后台HTTPS设置。**不要忽略证书错误或安装来历不明的证书。** 正常 Serve 无需手动导入证书。 |
| 已有 Serve 或 Funnel 配置 | 程序会拒绝启动，保留原配置。需要你确认旧服务用途并自行停止；不要为本程序开启 Funnel。 |
| P1 源码不匹配 | 选择 PR #3 最新代码的 p1 目录，不要选择数据目录或 K2 Python 目录。 |
| JSON或路径无效 | 使用此前已验收数据根目录的 snapshots/market 文件；保留 `.local-only`，不要放到 OneDrive、仓库或网络盘。最多选 16 份行情，总输入不超过 32 MB、每份不超过 P1 原上限 8 MB。 |
| 未能确认 Serve 已关闭 | 数据接口和会话先行关闭；请退出 Windows Tailscale 确认断开，再处理旧配置。 |

云端开发不能替你完成 Windows 权限批准、Tailscale 账号登录、后台 HTTPS 启用、私人文件选择或实际 iPhone Safari 证书验收。无需把持仓文件、配对码或密钥发给 Codex。
