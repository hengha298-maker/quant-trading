# 养鹅：真实持仓与当日研究整合

这是基于现有V3.3提交f5c4bac的增量整合，不修改V1.1/V2/P1/V3.1/V3.2/V3.3验收工作区。没有新数据格式迁移或交易接口。

唯一启动入口：仓库根目录 `Start-Investment.cmd`。它打开控制窗口和电脑页面；手机地址由窗口“复制 iPhone 私有报告地址”取得。当前复用已有9394/10001路由，不改Tailscale配置。关闭窗口会停止服务；重启沿用同一私有链接。可用“重置手机链接”撤销旧链接，报告保留。

使用：分别选择券商，CSV/XLSX预览核对或手动输入当前数量、成本、现金及记录日期；确认后仅新增本地快照。点击“更新行情与分析”，得到真实公开行情、前收盘对MA20、交叉对照、风险与同区间价格回测。历史数量没有预填。两券商分别保存，旧文件不覆盖。

## 本轮真实验证与限制

- 2026-10-28收盘后公开腾讯报价：600900.SH 29.40元、515450.SH 1.449元。东方财富分钟收盘快照与其数值一致；不是独立交易所源认证，也不是盘中持续可靠性认证。
- 获取两标的2025-12-12至2026-10-28共210条未复权日线；另存独立前复权序列。原V1信号准确使用前一个完整交易日收盘及包含该日20日均线，不冒充均线交叉。
- 原V1同一东方财富**日线**请求复测仍失败（requests ProxyError、urllib RemoteDisconnected），不能通过分钟端点恢复断言日线已修复。新报告独立使用腾讯日线；原14:50任务完全保留。
- 前复权可显示趋势与除权影响，但不是已核验分红现金流。四策略比较仍是未复权价格路径、显式假设费用，不标成完整含息收益。缺少实际分红税/再投资/费率时不能作长江电力总收益结论。
- 未取得当日用户确认持仓时，只显示关注标的研究；缺成本/现金保持未知。手动输入是用户确认事实，不是券商自动验证。
- 自定义未审阅标的只显示身份/单位待核验，不猜价格。2027日历在网络请求前阻断。
- 私有数据在 `investment/work/private`，报告与原始公开响应在 `investment/work/runs`，全部Git忽略。CSV/XLSX账户身份字段不保留；无云上传、调试遥测、券商登录、真实订单或隐式Bark。

## 手机与既有离线应用

新 `/investment/` 页面经本次随机凭证访问私人电脑服务，需要Windows及Tailscale在线。它没有伪装成可独立离线获取当天行情的App。可下载兼容 `goose-investment-report` version1 文件，在原iPhone应用手动导入后离线保存。原应用根路径、IndexedDB、账本、加密备份不变。新页面不将财富数据放入共享HTTP缓存或ServiceWorker；访问密钥只在私人地址的片段和浏览器会话中使用，片段不会随HTTP请求或引用来源发送；手机收藏完整私人地址可在新会话恢复。电脑侧仅存本机私有访问目录，不写入报告、日志或仓库。请勿把私人地址转发他人。

## 本轮实用性完善

- 券商原报盈亏与按本次报价重估差额并列；保留原值、来源日期、成本价精度及费用口径，未知不填零。占比两位小数，同代码跨券商合并计算集中度。
- 最新完整交易日趋势与原V1前收盘对MA20分开；显示量比、回撤、波动及前复权对照。四种情景有各自计算依据、触发条件和暂停条件，均不生成订单或臆造资金预算。
- 手机链接跨正常重启保持有效，可明确撤销。无需每日重新安装或重复配对；电脑与当前控制窗口需在线才能查看新报告。
- 交易日14:38分析、14:43:30停止采集、14:44发送截止的完整流程已实现。默认仅预览，真实通知及任务启用另行批准。详细权限、去重与失败行为见根目录AUTOMATION.md。

手机共享会只读复用现有安全路由；若重启电脑后临时路由不存在，唯一控制入口会恢复本程序持有的前台私网分享。不会创建系统服务或持久Tailscale配置、不会覆盖其他路由、不会启用Funnel。
