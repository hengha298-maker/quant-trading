# 养鹅计划 V3 · 离线财富手账 MVP

实际可用的中文手机优先 PWA：总览、资产、流水、设置与备份四页。Windows 与 iPhone 各自保存自己的账本；**本阶段没有双向同步**。

## 启动与首次安装（3 步）

1. Windows 双击仓库根目录 `Start-V3.cmd`。电脑页自动打开；需要手机首次安装时，连接两端 Tailscale，点击控制窗口的“开启 iPhone 首次安装服务”，用 Safari 打开显示的 HTTPS 地址。权限或首次 HTTPS 确认由用户本人完成，不跳过警告。
2. Safari 分享 → 添加到主屏幕。**从新图标在线打开一次，等状态显示“离线就绪”**，再录入账户。Safari 标签与主屏幕 App 的数据容器可能独立；已有标签数据请先导出加密备份，再在主屏幕 App 恢复。
3. 用虚构数据录入一笔，开启飞行模式、彻底关闭并重开 App，再新增/修改一笔并确认重开仍在；导出加密备份，在恢复预览中验证。此步骤必须在真实 iPhone 上由用户验收。

安装并缓存完成后，Windows 可关闭、Tailscale 可断开，手机仍可记录和查看已保存数据。首次安装、资源更新、从空存储重新安装仍需连接安装服务。不要更换 HTTPS 主机名/端口来当作同步，它们属于不同 origin 和独立账本。

V3 手机安装服务使用独立端口 `10000`，仅前台 Tailscale Serve 代理 `127.0.0.1:9393`；不使用公网 Funnel、后台 Serve、reset、ACL 修改。关闭窗口只停止自己创建的服务。冻结 V2 的服务所有权检查可能拒绝并发分享，使用 V2 前先停止 V3 安装服务。

## 可用功能与计算口径

- 银行、支付/现金、证券、基金、其他资产、借款和信用卡账户，支持名称、日期、未知余额、备注与负债利率（记录，不自动计息）。
- 收入、支出、转账、余额调整、负债还款、投资买入/卖出/分红；可修改、撤销、查询。账户删除采用归档，保留历史且仍计入其余额，避免隐藏账户悄悄抹去财富；需要清零须明确记录余额调整。
- 金额只使用 **BigInt 整数分字符串**；最多两位人民币小数，拒绝浮点、科学计数法和超限值。未知值为 `null`，不会当作零；有未知账户时完整资产/负债/净资产保持未知。
- 转账、投资买卖和还款本金不计为收入/支出；还款利息计支出。投资买卖记录现金与投资账户之间的成交额流动，不推算实时价格、成本或盈亏。
- 证券账户余额应填写包含持仓的账户总额。P1 手动导入仅保存历史数量、来源、日期、未知现金/成本和 SHA256 指纹，**不创建额外资产价值、不重复计入总资产**。不会加载行情，也不会将 515450 的未核验历史行情变成当前市值。
- 每次编辑/撤销保留审计，按记账日期回放余额，未来流水不进入当前总览。历史净资产仅反映明确录入的余额和流水，不是投资收益曲线。

## 数据、恢复与边界

- IndexedDB 的数据库版本与账本 `schemaVersion: 1` 分离。版本 0 → 1 有显式无损迁移；拒绝未知未来版本，不重置为空。
- 当前记录包含 SHA256 校验；同一事务写入当前与上一完整恢复副本。损坏时显式提示回退副本；两份均坏时阻断普通写入，只允许用户从验证过的备份明确恢复。
- 多标签使用 revision 乐观并发检查；过期窗口不能覆盖新数据。配额失败不提示保存成功。
- 完整备份使用 AES-GCM-256、PBKDF2-SHA256（600000 次）、每次独立随机盐和 IV，头信息也参与认证。密码不保存且无法找回。明文账本限 8 MiB、加密包限 12 MiB。
- 恢复先解密、校验、迁移、显示数量与冲突，再明确合并或替换。相同 ID 不同内容禁止自动合并；完整替换前要求导出当前账本并确认已另存。文件下载并不能证明已妥善保管。
- **iOS 网站存储不是永久备份**：系统清理、卸载、清除网站数据、换机都可能导致丢失；持久存储申请不是保证。请定期将加密导出文件保存在独立位置，至少保留两份并试恢复，密码另行妥善保存。
- 本机数据库没有额外口令加密，应使用设备锁和可信系统账户；加密只用于导出备份。本程序无分析/调试云服务，不自动上传数据。服务器只发白名单静态文件，没有财富数据 API、文件上传或同步接口。

## 开发与验证

无需安装运行时 npm 包或改系统 Python：浏览器原生模块、IndexedDB、Service Worker、Web Crypto；Python 3.12 标准库仅分发静态代码。优先复用现有 D 盘解释器，备选 `py -3.12`。

```powershell
node --test v3/tests/*.test.mjs
py -3.12 -B -m unittest discover -s v3/tests -p test_server.py -v
# 可选浏览器回归：既有 Playwright 1.62.1 + 已安装 Edge，非生产依赖
node v3/tests/browser.cjs
```

浏览器回归前运行 `py -3.12 -B v3/serve.py`。Playwright 通过 `NODE_PATH` 指向本机已安装的包，测试仅使用隔离浏览器上下文与虚构数据；生成物在被忽略的 `v3/work`，不应提交真实备份。

本工作区从 `main` 建独立分支，新增功能仅在 `v3/`、独立入口与 V3 CI，不修改 V1、冻结 V2/P1 或稳定数据。开发仓库与 `Goose/Data` 为兄弟路径，不把私人数据放进 Git。

## 依赖与许可证

生产第三方依赖 **0 项**；锁文件记录无外部 npm 依赖。新写 V3 代码的 MIT 许可仅适用于 `v3/`（见 `LICENSE`），不改变仓库其他代码许可。可选测试工具 Playwright 固定已安装版本 1.62.1，Apache-2.0；Node/Python/Edge 均复用本机安装，不重新分发其程序文件。

设计依据：[WebKit 存储政策](https://webkit.org/blog/14403/updates-to-storage-policy/)、[Safari 17.2 主屏幕数据容器](https://webkit.org/blog/14787/webkit-features-in-safari-17-2/)、[Service Worker](https://developer.mozilla.org/en-US/docs/Web/API/Service_Worker_API/Using_Service_Workers)、[AES-GCM](https://developer.mozilla.org/en-US/docs/Web/API/AesGcmParams)、[PBKDF2](https://developer.mozilla.org/en-US/docs/Web/API/Pbkdf2Params)、[Tailscale Serve](https://tailscale.com/docs/reference/tailscale-cli/serve)。
