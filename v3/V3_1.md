# V3.1 投资决策 MVP

本地优先，四个页面为决策、资产、流水、设置与备份。日常记账是可选辅助功能。没有券商连接、实时行情采集、自动交易、Windows 双向同步或第三方 AI 调用。

## 实际运行

在仓库根目录双击 `Start-V3.cmd`。沿用既有 `127.0.0.1:9393` 与私人 HTTPS 安装入口，避免为已安装应用改变存储来源。手机安装服务由控制窗口显式开启；不创建计划任务、系统服务或公网 Funnel。V2/P1 的 `Start-Goose.cmd` 不变。

原 V3 数据库名称与存储区不变，数据库版本无损升至 2；旧客户端的版本 1 打开会被拒绝，防止旧代码覆盖新增规划。旧账本自动补空的 `planning` 扩展，不重算或覆盖账户、流水、P1 导入。扩展版本为 1，含资产快照、关注标的、报告和工资奖金计划。新加密备份 envelope 为 2，新版仍能读旧版 1；旧应用会拒绝新版备份，避免静默丢失扩展记录。恢复预览包含各类数量、同 ID 和语义冲突；冲突不自动覆盖。

应用更新采用等待式 service worker：先导出已有数据的加密备份，关闭该来源的所有 Safari 标签及主屏幕应用，再联网打开并等待“离线就绪”。不要清除浏览器数据。iOS 网站存储可被系统清理，必须把备份另存于可靠位置并保存密码；本机账本本身未加密。Safari 标签和主屏幕应用也可能使用独立存储。

## 数据边界

- 每份资产快照是某日完整账户集合，不能与旧账本总额相加。证券账户总额已含持仓；P1 历史数量只作参考，不再次估值。
- 快照空金额为未知。任一资产或负债未知，完整净资产未知。新快照或修订保留历史，撤销保留标记。
- 工资助手的现金口径是**到账前**、用户当日确认的余额。未知或陈旧条件只允许保存草稿，不确认收入。所有金额以整数分计算。
- 分配顺序是必要现金保障、还款、手动定投、储蓄、自由支配；金额不足封顶并警告。风险偏好只是标签，不推断收益，不选择证券。可以编辑金额，但合计不能超过已知资金上限；确认计划仍须保留应急及必要支出、不能超额还债。
- “确认收到工资”与确认分配分开。只有当日到账前资产快照与计划现金一致、用户指定账户并确认，才新建一份只增加本次收入的快照。分配金额不会自动转账、还款或生成交易；同一计划拒绝重复入账。
- 本版使用一组手工确认的负债余额、利率、到期日与拟还本金，不自动计算应计利息或多笔负债的最优偿还顺序。多个负债须先核实资金安排，未知条件不能确认。
- 不自动读取任何真实持仓、V1 数据库或研究目录。通过文件选择手动导入 P1 历史快照或结构化报告。真实报告的来源声明不代表本应用复算或认证。

## 量化报告接口

`planning.js` 的 `saveReport` 校验 `goose-investment-report` version 1：来源、数据日期、生成时间、策略、标的、信号依据/风险/证据质量、可选回测和模拟成交。相同来源、日期、策略重复导入被拒。超过 3 个自然日标记陈旧；该阈值不是交易日历，也不能据此认定未超过阈值的报告可实盘执行。无报告、无回测或无成本明确显示缺失，不补造数值。

回测收益与成本字段使用整数 basis points；金额与模拟价格使用整数分。界面展示的是报告来源声明的结果，不能把模拟成交等同历史回测绩效。持有、观察、分批买入/减仓仅作为有条件情景，不从缺少的行情生成价格或仓位建议。

`buildReviewPackage` 只在本机生成结构化 JSON，事实带来源与日期，`modelInferences` 与 `actionSuggestions` 初始为空。历史日期导出不包含其后的报告、计划或持仓快照。导出的个人文件仍需自行妥善保管；没有后台 AI 请求。

## V1 接入前诊断边界

原 V1 为前一交易日收盘与 20 个完整交易日均线比较的模拟策略，严格检查行情日期与新鲜度；代码目前没有可供展示的正式历史回测报告。分钟行情代理连接失败时应阻断，不使用缓存伪造今日信号。原始日志、数据库、Bark 配置及本机诊断保留在本机，不进 Git。

14:45 不能消费尚未执行的 14:50 任务结果。后续如获批准，应另建只读健康报告和脱敏提醒，记录数据源时间、接收时间、日线截止日与异常码。原任务、原策略和 Bark 密钥在本轮不变；本轮没有新增任何提醒任务。

## 测试与许可

运行 `node --test v3/tests/*.test.mjs`、Python `unittest` 和两个独立 Edge 浏览器回归脚本。浏览器测试只使用虚构数据和独立上下文，包含离线重开、备份恢复、冲突与异常保护。Edge 测试不等于 iPhone 实机验收；新版本的 iPhone 测试须用户完成。

V3.1 未新增运行依赖。继续使用浏览器原生 IndexedDB、Web Crypto、service worker 与 Python 标准库；新 V3 代码许可证见 `v3/LICENSE`，不重新许可旧仓库代码。自动化浏览器测试使用已有 Playwright（Apache-2.0）。
