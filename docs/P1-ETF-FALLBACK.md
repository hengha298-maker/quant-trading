## 真实联网结论：尚未验收，不启用

用户提供的 Windows 实测是：东方财富 `600900.SH` 返回727条，截至2026-10-22；`515450.SH` 两次 `RemoteDisconnected`。这是用户本机观察，本轮开发环境未独立复现这727条，也未读取或上传用户的持仓及采集文件。

本轮在独立工具环境安装 `akshare==1.19.1`、`py-mini-racer==0.6.0`，检查了原 `fund_etf_hist_sina` 实现：它请求新浪的固定日线压缩文件，用本地 `hk_js_decode` 解码，再以 pandas 转型、排序。代码存在或包安装成功不代表515450数据可用。

实际请求以下固定 URL，默认代理返回 `URLError / Tunnel connection failed: 403 Forbidden`，请求未取得源站数据：

```text
https://finance.sina.com.cn/realstock/company/sh515450/hisdata_klc2/klc_kl.js
```

独立命令 `python -m goose_research.probe_sina` 实际退出1，输出 `unavailable（SinaResponseError）`。执行环境配置仍为受限白名单，未包含 `finance.sina.com.cn`。用户已授权放行，但实际出口配置尚未生效；没有改代理、绕过域名策略或关闭 TLS 校验。由于下载失败，原 API 的真实数据比较尚未运行成功，**不能声称已验证真实行数、价格、截至日期或备用源可用**。

因此代码保留 `SINA_DAILY_VERIFIED = False`：默认仍先用东方财富；主源失败则保存不可用记录，明确标记新浪 `skipped / SourceNotVerified`。显式 `--source sina` 也不能绕过门禁。真实核验完成并复核结果前不启用；探测本身永远不改变门禁。

## 已实现的独立候选与回退路径

- 新增 `sina.py`，只允许 `515450.SH` 日线及固定 HTTPS URL。拒绝重定向、错误证券包装、过大/截断响应；保留默认代理与 TLS 验证。不会执行返回内容中的任意 JavaScript。
- 可选固定 AKShare 本地解码器放在45秒子进程中，下载15秒、8 MB上限，单次JS调用5秒/128 MiB。默认 P1 导入、东方财富采集和离线测试不依赖 AKShare。
- 在裁剪三年请求区间之前，检查完整原始历史：代码包装、严格日期升序、无重复/未来值、有限正 OHLC 及高低价关系、非负成交量、日期范围；不先排序来掩盖异常。
- `auto` 保留主源；主源整批失败时只在真实验收门禁已开启的版本尝试备用。主源成功不访问备用，单批只保留一个来源。两源失败输出 `unavailable`、空 rows、来源尝试记录，不沿用部分结果或先前行情。
- 成功的候选批次记录固定来源 URL、原响应 SHA256、解码器版本、原始范围/条数、采集时刻和日期要求。复权口径保留“源站原始价格（复权口径未核验）”，成交量保留源站原值（AKShare文档称“手”，未独立核验），不乘除100、不与东方财富拼接。
- 未核验复权的候选只可展示事实，不进入费用参考。所有 P1 路径仍不产生交易建议或真实委托。报告按最后行情日期显示距报告日的自然日，不把新下载的旧数据称为实时行情。

新命令 `probe_sina` 不接受数据目录、不读持仓、不保存行情：先验证真实响应及原始顺序，再把**同一个真实下载内容**交给原 `akshare.fund_etf_hist_sina(symbol="sh515450")`，在隔离进程中逐行比较日期和 OHLCV。仅替换原 API 的下载传输以复用同一响应；不替换数据或生成价格。若 API 请求其他地址、结果不一致或过旧即失败。它输出公开元数据摘要；即使通过，也不证明复权、量单位、交易日历完整性或任何策略收益。

## 日期、兼容与不可覆盖

日线默认目标为北京时间16点前上一工作日、16点后当日，周末向前回退。请求结束日就截止到该目标，排除未结束当日日线。该规则**不是交易所日历**，节假日可能保守失败；`--expected-last-date` 只供独立核对的最后完整交易日使用，不能填写未来或16点前当日来放宽检查。元数据保留日期依据，`calendar_verified` 始终为 false。不承诺三年完整。

旧 schema_version=1 快照与行情记录仍可读，不原地升级；新增校验针对来源、复权、时效与原始范围的一致性。每次 `collect` 仍用新 UUID 文件排他写入，失败也保存新记录，绝不覆盖持仓或旧行情。`collect` 退出0仅表示记录保存，`probe_sina` 退出0才表示该次限定核验通过，两者都不是投资建议。

防误提交工具保留 Git 模式；源码根没有 `.git` 或未安装 Git 时，明确降级为文件系统全量扫描。实际 Git 故障不能伪装成功。全量扫描不信任 `.gitignore`，拒绝链接、Windows reparse point、不可读文件和可疑文件名；只排除根 `.git` 元数据。它不是秘密内容扫描器。
