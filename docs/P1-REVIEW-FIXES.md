## 三项修复

### 1. 统一校验所有报告输入

新增标准库 `validation.py`，CSV导入、行情采集、JSON保存/读取、直接render均使用统一规则。文件入口先验证，全部通过才创建HTML目录和报告文件；直接调用render也不能绕过验证。不对乱序行情悄悄排序，不把非法价格继续用于费用分析。采集到不合法响应时，清空条目及成功元数据并标记 unavailable；不合法的本地JSON则拒绝整份报告。

- schema_version只能为整数1，不接受999或布尔值。快照/账户/持仓/行情/行记录校验结构及已知字段，拒绝遗漏和未知字段。
- 快照日期、证券代码、账户唯一性、同账户持仓唯一性、同证券类型一致性、完整账户现金、整数持仓/可卖数量及非负关系统一验证。成本仍允许未知或有限负值，未引入真实累计收益。
- 数值拒绝布尔、NaN、Infinity、非数值及过大指数；支持绝对值≤1e15、小数最多12位，超限明确拒绝，避免费用计算溢出。历史真实负成本仍有效。
- 日线时间为YYYY-MM-DD，分钟为YYYY-MM-DD HH:MM（北京时间）。拒绝未来时点、重复/乱序、请求区间外数据、晚于采集时刻的数据及非正价格/非法OHLC/负成交量。采集时刻须含时区；返回条数、范围和滞后信息须与行数据一致。
- JSON读取限制8MB，拒绝重复键、非法常量及格式错误。错误文案不回显输入内容；没有新日志或遥测。

### 2. Windows仅允许可确认的本地固定磁盘

在解析前拒绝UNC、扩展/设备命名空间和驱动器相对路径；调用Unicode Win32 GetDriveTypeW，只有DRIVE_FIXED通过，映射网络盘、未知盘、不可确认结果均拒绝。先核验原盘，再严格解析最深已存在祖先（支持未来新建子目录），最后对真实目标再次核验。损坏、循环、不可访问链接及不支持的重解析点安全拒绝；同时核对原路径和目标是否为仓库/已知同步路径。

Windows CI专项测试：原生Win32本地中文目录与不存在子目录；UNC不触发解析；映射盘拒绝；解析后UNC/映射盘目标拒绝；真实本地联接点正常使用及指向仓库的联接点拒绝；未知盘拒绝。映射盘和远端目标采用API/解析边界模拟，不挂载或连接真实SMB共享；真实联接点通过Windows mklink /J创建并清理。所有平台另测驱动器状态和Unicode参数。

### 3. HTML展示关键资产事实

按账户显示快照录入的可用现金或未知，完整空仓账户仍展示现金；局部账户未填持仓时不能称为真实空仓。每项持仓展示股票/ETF类型、总数量、真实录入可卖数量、券商成本/未知和快照日期。schema v1仅有日期，明确“未记录日内时刻”，不伪造时间。软件100股/份情景单独标注，不把它或历史可卖数量冒充当前可卖数量。
