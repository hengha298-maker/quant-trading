# 养鹅计划 V2.0-P1 修订设计

本设计依据 2026-10-19 审核意见形成，作为本 PR 的开发与验收基线。仓库内没有独立的旧版 V2 设计稿，不能逐段追溯旧稿；以下明确全部修订约束。

## 隔离与数据流

`本地 CSV → 整表校验 → 新增 UTF-8 JSON 快照 → 显式选取快照/行情批次 → 本地离线 HTML`。

P1 代码在 `p1/`，标准库独立运行，不安装 V1 依赖、不调用 quant_paper，不读取其配置、SQLite、日志或 Bark。无需运行原 scripts 中任何脚本。P1 无计划任务、守护进程、券商接口、交易凭证、交易信号或实盘开关。新增 CI 只是代码测试，不是投资研究定时任务。

## 十项修订

1. 提供 UTF-8 BOM CSV 模板，适合 Excel/记事本编辑，JSON 为内部保存格式。整表校验成功才生成快照；UUID 与排他创建保证不覆盖旧快照。非法代码、重复标的、日期、数量、现金、可卖数量、无穷值、账户元数据冲突均拒绝。不支持任意券商导出格式自动猜列。
2. 费用均明确为示例；华宝股票/ETF免五，银河ETF免五且佣金较低按用户说明表达，费率数值没有核验。另设保守压力情景（包含最低5元压力项，明确非实际券商规则）。印花税、过户、滑点也都是可审阅的情景参数。
3. 成本保留券商显示口径，允许未知及有限负数（历史分红可能使显示成本为负）。无完整流水，固定不计算真实累计收益率；即使用户声明完整持仓，也不等于完整流水。
4. 数据模型：版本、快照日期、多个匿名账户，各有券商、完整性、现金、持仓列表；持仓含证券、类型、总数量、可卖数量和成本。支持现金空仓账户，可只填600900.SH及515450.SH。P1 保守限定境内股票/ETF与人民币现金，其他资产须标记账户 partial。所有账户均不输出配置占比，防止局部数据被误称全账户配置。
5. 免费公开东方财富接口，日线默认请求最近三年不复权；记录请求/返回范围、条数、时间、滞后及工作日候选缺口（包含节假日/停牌，未核对交易所日历，不代表确定漏数）。分钟只报告实际返回范围，不承诺长期分钟历史。每次手动采集独立留档，支持以后持续累积；不填补、拼造历史。
6. 费用模型预留 buy_then_sell / sell_then_buy，只输出100股/份同价往返佣金、税费、过户、双腿滑点、盈亏平衡价差及现金/可卖底仓约束。两种顺序都要求已有可卖底仓，不能卖出当天新买股份。不验证实时订单可成交性。
7. 仅手动运行，报告不联网、不加载外部资源，不增加定时任务。
8. HTML 分别展示行情事实、费用假设、研究结论、不可用状态。行情异常保存 unavailable，报告仍可生成；不以抓取时间替代源行情日期。
9. 未来定投、日内T、复盘、Bark摘要和手机阅读可分别新增分析器与报告输出适配器；schema_version、独立行情批次、方向字段及报告边界是扩展点。本期没有实现这些业务；HTML只有基本窄屏换行。
10. 数据仅在用户指定且确认非同步的仓库外目录。检测 Git 根及父目录（含 worktree）、解析符号链接、拒绝常见云同步目录和 OneDrive 环境变量路径。非同步确认无法替代用户检查其他同步软件；Windows文件访问控制/磁盘加密由用户管理。源码和 CI 只有虚构数据；防误提交脚本拒绝结构化数据、报告和备份文件，不能识别任意改名或嵌入源码的隐私，仍须人工审阅。

## 明确不具备的能力

没有交易所完整日历审计、证券身份权威核验、复权总回报、分红税、过往流水重建、实时盘口/停牌/涨跌停判定、资金交收模型、多币种、多资产估值或盈利预测。账户 complete 是用户声明，不自动证明完整。成本情景不是实际可成交判断，不足状态必须保留。

## 可复现与故障处理

显式选择快照和行情路径，不暗中使用最新文件。不自动覆盖模板、快照、行情或报告，不修改原始 CSV。保存时进程中断可能留下不完整新文件，读取会失败；可删除该未完成文件或恢复备份，历史文件不受影响。多人并发修改目录和恶意本机进程不在权限防护范围内。行情接口变化、限流或网络失败均记不可用，不退回虚构数据。
